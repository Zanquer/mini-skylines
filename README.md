## 🌟 v7.0 Phase 1 旗舰升级一览

### 1. 📱 iPhone 全屏离线高清 PWA 架构 (`src/asset_loader.js` & `www/`)
- **外置二进制 PBR 资产解耦**：告别 3.9 MB 单文件内联阻塞，主程序精简至 `~780 KB`，全部 **14 套高清 PBR 物理材质（42 张 Albedo 768×768 + Sobel Normal 512×512 + Physical Roughness 512×512 贴图）**、模型与 iOS 桌面图标外置存储，Safari 解析提速 5 倍。
- **✈️ 飞行模式离线高清包管理器**：游戏内实时查看离线缓存项数与体积，一键缓存全量资源；采用**自动版本哈希 Network-First Service Worker**，有网自动拉新版本、断网零延迟秒开。
- **💾 IndexedDB + localStorage 双保险离线存档**：自动存档与 3 个手动槽位双写持久化，防 iOS 清理存储丢档。

### 2. ⚡ iOS WebGL 零泄漏高性能引擎 (`src/renderer3d.js` & `src/simulation.js`)
- **600 帧零材质/几何体泄漏**：彻底重构动态渲染管线，烟雾、火焰、水雾、施工脚手架、预览格子、夜景辉光与灾害特效全部池化复用，告别 iPhone 久玩闪退。
- **6 批次 `InstancedMesh` 生态森林**：全城 1,500+ 棵树合并为 **≤ 6 个 Draw Call**，按海拔与地貌呈现**三层高山云杉/松树、四团非对称法国梧桐/金黄银杏阔叶林、东南海岸弯曲棕榈树**。
- **4 层静态网格独立脏标记拆分**：`terrainGroup / infraGroup / forestGroup / buildingGroup` 独立重建——普通楼宇建成或升级时跳过 168×168 地形与森林重建，彻底消除建城微卡顿。
- **3 档 iPhone 画质开关 (`✨ 高清旗舰 / ⚖️ 均衡流畅 / 🔋 极致省电`)**：动态调节 Retina 分辨率倍率、阴影贴图、夜景辉光与同屏车流上限。

### 3. 🎨 旗舰「去沙盒化」PBR 视觉与实景音画 (`src/architecture3d.js`, `src/terrain_water_shader.js`, `src/audio.js`)
- **全套 PBR 物理材质管线 + 建筑接触阴影 (Contact AO)**：玻璃幕墙镜面映照天空与晚霞、石材混凝土呈现真实砖缝凹凸法线，每栋楼宇底座自然贴合地面阴影。

- **实景街道家具**：主干道与桥梁自动批量生成**弧形 LED 路灯**（入夜点亮暖金光晕）；所有红绿灯路口生成**悬臂三色信号灯杆**，红绿灯颜色与 `traffic.isSignalRed()` 真实车流 100% 同步！
- **真比例现代 3D 车队 + 夜间车灯**：轿车、SUV、出租车、新能源纯电公交、集装箱货柜车、云梯消防车、绿白压缩垃圾车全部真比例精建，入夜自动亮起暖白前大灯与宝石红尾灯。

- **iOS 实景动态环境音 + 可开关背景乐 (BGM)**：随缩放高度与位置实时混音山谷风声、水坝激流与城市街景低鸣，并配舒缓城市建设背景电钢琴乐。
